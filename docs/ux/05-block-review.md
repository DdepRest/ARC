**Как читать таблицу.** Первая пара чисел — насколько каталог обходит дизайн-систему. Столбец «плотный чёрный» — вхождения `bg-black/80…95` (прямой запрет конституции там, где речь о модальных окнах). «Свой оверлей» — файлы с `fixed inset-0`. «Скроллбар» — упоминания собственных стилей прокрутки: их пять разных реализаций при отсутствии общей утилиты.
**Оговорка о единицах.** Столбец «строк» считан разбором содержимого, поэтому для файла, заканчивающегося переводом строки, значение на 1 больше результата `wc -l`; прежние замеры [`02-global-audit.md`](./02-global-audit.md) считались через `wc -l` — отсюда кажущаяся разница в одну строку по нескольким пространствам.

## 3. Новая доказательная база (что найдено в этом проходе)

Только факты, каждый проверен командой или чтением кода.

1. **Битые arbitrary-классы, 9 строк** `[замер]`: лишняя скобка в `var(--accent-bg-alpha))]` — `RecurrenceModal.vue:17,42,46,90`; `TaskConsole.vue:23,121,205,213`; `tasks.store.ts:356`. Декларация отбрасывается целиком: активный режим, чипы распознанных тегов и бейджи повторения лишаются акцентной заливки. (В [`04-tasks-settings.md`](./04-tasks-settings.md) указаны прежние номера строк — файлы с тех пор сдвинулись.)
2. **Невалидный оттенок** `text-rose-350` — `ObjectiveDetailsWorkspace.vue:76` `[замер]`. Оттенков `-350`, `-250`, `-450` в палитре Tailwind нет; `-950`, которых в проекте много, **валидны**.
3. **Двойная прозрачность** `text-white/60/70` и `text-white/60/60` — `ObjectiveDetailsWorkspace.vue:183,207` `[замер]`.
4. **Пустой колбэк отмены:** 10 из 45 вызовов `triggerSyncToast(..., () => {})` `[замер]` — тост показывает кнопку отмены, которая ничего не делает (4 из них в `MemoryView`).
5. **Показной объём RAM:** `TitleBar.vue:251-262` `[чтение]` — при отсутствии метрик объём считается как `memoryUsage * 0.08`, а всего памяти возвращается литерал `8.0`.
6. **Мёртвый `themeColor`** в `TitleBar.vue:246` `[чтение]` — вычисляется и не используется; рядом `z-index: 100000` в scoped-стиле (`:290`).
7. **Ошибка `STT ОШИБКА` без действия** `[чтение/скриншот]`: статичный текст с `title`, ни кнопки, ни перехода в настройки голоса.
8. **Четыре механизма уведомлений** `[чтение]`: тосты `CommandCenter.vue:104-109` (`z-[999]`, `bg-[#0d0e12]/95`), глобальный `SyncToast` (`z-[200000]`), локальный `UndoDeleteToast` (Commands), собственный баннер в `SettingsPanel`.
9. **Три реестра несуществующих пространств** `[чтение]`: `TabBar.plannedModules` (8 модулей, `selectModule` → `setActiveTab`), `SpotlightSearch.tabsList` (18 вкладок из `TAB_REGISTRY`), `ModulesView.modulesList` (13 модулей). Ни один компонент не рендерит `orchestrator`, `agents`, `tools`, `skills`, `architecture`, `scenarios`, `observability`, `sandbox` — переход ведёт в заглушку.
10. **Динамические классы Tailwind не работают** `[чтение]`: `SkillsTab.vue` собирает акцент строкой (`` `bg-${settingsStore.reactorColorTheme}-500/10` ``), но Tailwind сканирует исходники статически — реакция карточки макроса на тему ядра не появляется вовсе.
11. **Редактор макросов — сплошной чёрный экран** `[чтение]`: `MacroEditorView.vue:2` — `fixed inset-0 … bg-black` (в аудите зафиксировано как `bg-black/85`; уточнено при разборе).
12. **Бейдж `READY`** в шапке `TranscriptionView.vue` — статичная строка `[чтение]`.
13. **Реальная ошибка GPU не доходит до пользователя** `[чтение]`: `gpuWarningMessage` и `gpuName` получены из composable и не используются — вместо них захардкоженная фраза. Данные для честного сообщения уже есть.
14. **Нативный плеер подделан фильтром** `filter invert brightness-90 opacity-80` `[чтение]`.
15. **Микрофон чата работает через браузерный `webkitSpeechRecognition`** в обход собственного STT-стека; при отсутствии API запись имитируется `setTimeout(…, 2000)` — кнопка пульсирует две секунды и ничего не делает `[чтение]` (`ChatInputZone.vue:209-243`).
16. **Автоскролл без блокировки:** `ChatView.vue:371` — `onUpdated(() => nextTick(scrollToBottom))` сбрасывает чтение истории при любой перерисовке `[чтение]`.
17. **`select-none` на корне чата** (`ChatView.vue:3`) без единого `select-text` в пространстве `[чтение]`.
18. **Случайная подсказка ввода** `[чтение]`: `ChatInputZone.vue:153-168` — `Math.random()` по списку плейсхолдеров, часть из них со стареющими датами («за август»).
19. **Подставная модель в статусе** `[чтение]`: `ChatStatusBar.vue:140` — `props.modelName || 'A.R.C. Neural Core'`.
20. **Системность блока определяется регуляркой по тексту** `[чтение]`: `/ошибка|сбой|error|failed/i` в `MessageBubble.vue` — обычное объяснение ошибки помечается как системный сбой.
21. **Локализация четырьмя механизмами** `[чтение]`: объект `translations` пропсами (Memory — 4 получателя), пропс `localizations` (Vision, CommandCenter), `settingsStore.language` + инлайн-тернарники (10 файлов), двуязычный `TAB_REGISTRY` (`commands: 'КОМАНДЫ'`, `transcription: 'АУДИО'` среди 17 английских подписей).

## 5. Что из этого следует

**Первое.** Работы делятся не по пространствам, а по классам дефектов: грамматика интерфейса (обход системы) и правдивость состояния. Вторые опаснее: пользователь не видит, что цифра RAM не считается, что статус модуля — литерал, а микрофон не пишет. До сих пор они не были выделены в отдельный фронт — предлагается **F7 «Правдивость состояния»** с правилом: *любой индикатор обязан иметь источник данных или прямо говорить «нет данных»; нереализованное действие не изображается как рабочее*.

**Второе.** Три находки в чате (браузерный STT, два пайплайна вложений, автоскролл) — это не косметика, а поведение. Они объясняют, почему чат ощущается менее «своим», чем CORE, и должны идти в работу раньше визуальной полировки.

**Третье.** Пространства **не различаются по плотности и характеру**: Tasks, Memory, Files, Vision, Modules нарисованы одним набором приёмов (свой скроллбар, своё пустое состояние, сырая кнопка). Из-за этого конституционное разделение пространств по характеру не работает — и не заработает, пока приёмы не вынесены в общий слой (F1) и диалоговый слой (F2).

**Четвёртое.** Единственная блокирующая вещь по объёму — данные: `commands.registry.ts` 797 строк при лимите 800, `ModelManagerSection` и `PerformanceSettings` в настройках, `FpsOverlay` 964. Следующая небольшая фича в них валит сборку.

## 6. Порядок работ

1. **F1** — токены (слои, движение, типографика, цвет), общий служебный слой (единый скроллбар, стекло, вуаль, фокус), защёлка дисциплины.
2. **F2** — один оконный и уведомительный слой: четыре механизма → один; `ArcModal` с фокусом и стеком Escape; видимые ошибки вместо консоли.
3. **F7 (новый)** — правдивость состояния: показной RAM, `READY`, статусы модулей, `OPT_BRIDGE`, имитация записи, неработающая отмена, скрытая ошибка GPU, подставная модель.
4. **Живые исправления по ходу:** 9 битых классов, два невалидных класса, динамические классы Tailwind, два пайплайна вложений, автоскролл чата.
5. **F3 → F4 → F5 → F6** — локализация, псевдо-декор, размерная стена, доступность.
6. **Параллельно:** итерации A–E плана Tasks/Settings (правило стыковки — в [`03-roadmap.md`](./03-roadmap.md)).
