## 4. Что сделано хорошо

1. **`EmptyState` применён по назначению** — в блоках «Показатели» и «Решения», с человеческим описанием.
2. **Прогресс отката показывает реальные данные** (`rollbackProgress.current / total` + текст шага) — образец честной телеметрии, в отличие от псевдо-счётчиков в других местах.
3. **Секции свёрнуты** (`CollapsibleCard`): экран цели не вываливает всё сразу.
4. **Карта траектории рисуется по реальным узлам и связям** (SVG по модели данных), а не декоративно.
5. **Разделены состояния цели** (черновик → активна → завершена → заблокирована): интерфейс меняется по статусу, а не показывает всё сразу.

## 4. Что сделано хорошо

1. **Модульность:** каркас, тулбар, сетка и две модалки — отдельные файлы до 312 строк. Это эталон для остальных пространств.
2. **`EmptyState` в сетке** и понятные категории/сортировка/статистика в тулбаре — первый экран работает.
3. **Семантический поиск отделён от клиентской фильтрации** с debounce 250 мс и осмысленным поведением при переключении.
4. **Импорт проверяет форму данных** (ожидается массив узлов) и сообщает число импортированных узлов.
5. **Явность локального хранения**: экспорт/импорт JSON даёт пользователю контроль над своей памятью — важное свойство для доверия.
