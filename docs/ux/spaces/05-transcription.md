**Метод:** чтение кода целиком + сплошной замер.

## 1. Паспорт

- **Назначение:** расшифровка аудио и видео в текст с временной шкалой: выбор модели, устройство инференса (CPU / CUDA / DirectML), прогресс загрузки модели, плеер, список фрагментов, поиск по тексту, экспорт в `.txt`, отладочные логи.
- **Состав:** весь интерфейс — один файл `TranscriptionView.vue`; вся логика — один composable `useTranscription.ts` (841).
- **Владелец идентичности:** оболочка. В пространстве есть собственная шапка с описанием.

## 4. Что сделано хорошо

1. **Радиогруппа моделей сделана доступной** (`role="radiogroup"`, `role="radio"`, `aria-checked`, `tabindex`, Enter/Space) — единственный пример полной клавиатурной поддержки в проекте.
2. **Честный прогресс загрузки модели:** процент, имя файла и полоса связаны с реальным состоянием (`downloadPercentage`, `activeDownloadFile`).
3. **Предупреждение о первом запуске GPU** объясняет, почему первый прогон долгий — пользователь не принимает это за зависание.
4. **Возможность отменить расшифровку** во время работы (`cancelActiveTranscription`) — сценарий прерывания продуман.
5. **Поиск по расшифровке и экспорт в `.txt`** — прикладная польза, а не декор.
6. **Разделение `useTranscription.ts`**: логика вынесена из компонента (пусть и очень крупная) — представление не смешано с IPC.
