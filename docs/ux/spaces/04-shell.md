## 1. Паспорт

- **Назначение:** оболочка — постоянная рамка вокруг Реактора: статусная консоль сверху, канал связи снизу (док `TabBar` + `BottomBar`), плавающее стекло виджетов, поиск-прожектор, панель голоса, диагностические оверлеи.
- **Состав:**
  - `components/ui/TitleBar.vue` (381) — верхняя телеметрия, режимы, управление окном;
  - `components/ui/TabBar.vue` (391) — вкладки, закрепление, реестр подсистем, кнопка поиска;
  - `layouts/CommandCenter.vue` (193) + `layouts/composables/useCommandCenter.ts` (585) — сцена, стекло дока, тосты, оверлеи;
  - `layouts/components/HolographicProjectionPanel.vue` (209) — проекция содержимого вкладки вокруг ядра;
  - `components/ui/SpotlightSearch.vue` (230) — навигация ⌘K;
  - `components/voice/VoiceQuickPanel.vue` (366), `components/widgets/WidgetsLayer.vue`, `components/ui/ModelDownloadOverlay.vue`, `components/debug/FpsOverlay.vue` (964), `layouts/components/MusicCapsuleWidget.vue` (624), `NeuralLyricsOverlay` (48), `AwakeningOverlay` (24);
  - `components/ui/FallbackTabView.vue` — заглушка для вкладок без реализации.
- **Владелец идентичности:** оболочка и есть источник идентичности — это по конституции, менять не нужно.

## 4. Что сделано хорошо (важно не сломать)

1. **Реестр вкладок существует и используется** (`TAB_REGISTRY` в `TabBar` и `SpotlightSearch`) — нужен один источник, а не новый.
2. **`FallbackTabView`** — честная заглушка для нереализованных вкладок: переход в пустоту сообщает о себе, а не молчит.
3. **`TabBar` — единственное место с настоящими ролями** (`role="tablist"`, `aria-label` на стрелках прокрутки) и аккуратной деталью: активная вкладка сама подкручивается в центр.
4. **Тост `CommandCenter` не блокирует интерфейс** (`pointer-events-none` на контейнере) — правильная основа для единого слоя уведомлений.
5. **Закрепление вкладок и реестр подсистем** дают пользователю настоящую настройку навигации.
6. **Плавающее стекло виджетов** (`WidgetsLayer`) с ручками сворачивания — цельная механика, требующая только приведения фона к конституции.
