**Дата:** 19.09.2026

## Как поддерживать порядок

1. Новый вывод по UI-слою сначала попадает в аудит (`02`), затем в дорожную карту (`03`), затем — в план соответствующего фронта.
2. Выполненный пункт не удаляется: он получает отметку в реестре задач и уходит в `docs/current-state.md` как факт.
3. Находки делятся на два класса: **грамматические** (обход дизайн-системы) и **дефекты правдивости** (индикаторы и кнопки без источника данных). Вторые закрываются фронтом [F7](./fronts/F7-honest-state.md).
4. Если фронт меняет архитектурное правило (например, добавляет обязательное состояние примитива), обновляется сначала `01-vision.md` — правило первично, реализация следует за ним.
