# F3 — Локализация и реестр вкладок

**Фронт:** третий. **Опирается на:** F1 (внешний вид подписей) и выравнивание названий в [`../04-tasks-settings.md`](../04-tasks-settings.md).
**Основание:** [`../02-global-audit.md`](../02-global-audit.md) (дефект C11).

---

## 1. Задача фронта

Сейчас двуязычность существует **в виде исключений**: `locales/ru.json` и `locales/en.json` содержат по 10 ключей и не подключены ни одним компонентом, а переключение языка живёт инлайн-тернарниками в 10 файлах (`store.language === 'EN' ? 'Save' : 'Сохранить'`). Остальной текст жёстко русский.

Отдельно смешан сам реестр имён вкладок: `TAB_REGISTRY` содержит `'КОМАНДЫ'` и `'АУДИО'` рядом с `'CORE'`, `'CHAT'`, `'MEMORY'`, и перечисляет 19 имён, из которых 8 не имеют реализованного пространства.

Целевое состояние: **один словарь на язык, один способ получить текст, единый язык подписей, реестр отражает то, что реально существует.**

## 3. F3.1 — Структура словарей

Группировка по пространству и разделу, чтобы ключ читался как адрес:

```jsonc
{
  "common":     { "save": "Сохранить", "cancel": "Отмена", "close": "Закрыть", "undo": "Отменить" },
  "shell":      { "projection_active": "ПРОЕКЦИЯ · АКТИВНА", "space": { "core": "ЯДРО", "chat": "ЧАТ" } },
  "settings":   { "nav": { "general": "Быстрые параметры", "appearance": "Интерфейс и тема" } },
  "tasks":      { "queue": "Очередь задач", "completed": "Готово", "empty": "Список задач пуст" },
  "voice":      { "listening": "Слушаю", "processing": "Обрабатываю" },
  "errors":     { "network": "Нет соединения. Проверьте сеть", "malformed_json": "Неверный формат файла" }
}
```

Правила структуры:

1. **Раздел `errors` обязателен** — он напрямую поддерживает правило честной ошибки из F2.
2. **Никаких ключей-синонимов.** Если два места называют одно и то же, ключ один.
3. **Максимум два уровня вложенности** — глубже становится тяжело искать.
4. **Технические термины — латиницей и без перевода:** `CPU`, `RAM`, `GPU`, `STT`, `TTS`, `API`, названия моделей и провайдеров. Это Машинный слой, он интернационален по определению.

## 4. F3.2 — Доступ к тексту

В проекте уже есть `composables/useLocale.ts` — расширяем его, а не создаём второй механизм:

- получение подписи по ключу с подстановкой значений;
- текущий язык и переключение;
- склонение по числу (см. F3.6);
- форматирование даты и времени (см. F3.6);
- поведение при отсутствии ключа: показывается сам ключ и выводится предупреждение в консоль (в разработке), чтобы пропуски находились сразу, а не глазу пользователя.

## 5. F3.3 — Уборка инлайн-переводов

Файлы с инлайн-переключением языка: `FpsOverlay.vue`, `SyncToast.vue`, `VoiceQuickPanel.vue`, `ChatView.vue`, `MemoryView.vue`, `SettingsMenu.vue`, `SettingsPanel.vue`, `STTSection.vue`, `TabNavigationSection.vue` — всего 9 подлежащих правке (в аудите указаны 10 вместе с `BottomBar.vue`).

**`BottomBar.vue` исключается** — файл входит в зону «НЕ ТРОГАТЬ» по `AGENTS.md`; он остаётся как есть до отдельного решения.

Порядок: сначала `SyncToast` и `SettingsMenu` (мало текста, высокая частота использования), затем пространства.

## 6. F3.4 — Реестр вкладок

`TAB_REGISTRY` — единственный источник имён пространств (его уже использует палитра команд). Требования:

1. **Единый язык подписей.** Сейчас смешаны русские и английские имена. Решение: русские названия для пространств, доступных пользователю, латиница — только для технических терминов внутри Машинного слоя.
2. **Разделение состояния.** В реестре явно отделяются пространства, которые существуют, от планируемых (`orchestrator`, `agents`, `tools`, `skills`, `architecture`, `scenarios`, `observability`, `sandbox`). Реестр текущего интерфейса не должен выглядеть как карта будущего.
3. **Проверка полноты.** Каждому имени с состоянием «есть» соответствует реальный компонент в оболочке — иначе реестр расходится с интерфейсом (тот же класс ошибки, что «мёртвые» пункты навигации в Settings).

## 7. F3.6 — Плюрализация и даты

Сегодня склонения написаны руками прямо в компонентах: в телеметрии задач живут две почти одинаковые функции склонения, рассчитанные на разные падежи. Даты и время форматируются в 14 местах напрямую через `toLocale*`, часть уже была предметом отдельного исправления (защита от не-`Date`).

Вводится один утилитарный модуль: склонение по числу (русские правила: 1 задача / 2 задачи / 5 задач), формат относительного времени («сегодня», «завтра», «просрочено 2 дня»), формат абсолютной даты и времени. Все места, форматирующие даты и числа вручную, переводятся на него.

---

## 8. Definition of Done фронта

1. Ни одного инлайн-тернарника языка в шаблонах (кроме `BottomBar.vue` как согласованного исключения).
2. Словари покрывают все затронутые пространства и содержат раздел ошибок.
3. Реестр вкладок одноязычен, разделён на «есть/планируется» и проверяется на полноту.
4. Склонения и форматирование дат — в одном модуле.
5. Отсутствующий ключ обнаруживается в разработке, а не показывается пользователю как сырой текст.

## 10. Риски и их снятие

| Риск | Снятие |
|---|---|
| Перевод меняет ширину элементов (кнопки, бейджи, вкладки) | После перевода каждого пространства — ручная проверка вёрстки при минимальном размере окна |
| Ключи расходятся с текстом по смыслу | Один ключ на сущность; при сомнении — сверка с подписью в интерфейсе |
| Появление «полуанглийского» интерфейса | Правило из F3.1: технические термины латиницей, человекочитаемое — переводится |
| `BottomBar.vue` остаётся в стороне и начинает расходиться | Зафиксировано как известное исключение с пометкой в `docs/current-state.md` |
