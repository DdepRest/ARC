# Релиз v1.0.0 (Производительность & Оптимизация памяти)

## Критические исправления
- [x] **Утечка GPU (17 MB -> 134 MB)**: Реализован глубокий каскадный `dispose()` для всех Three.js текстур (`map`, `envMap` и т.д.) и объекта `bloomPass`. Это ликвидировало монотонный рост потребления видеопамяти.
- [x] **Утечка Heap (21 MB/min)**: Решена критическая проблема лавинообразного создания массивов `Float32Array` в AudioWorklet. Теперь данные записываются в предварительно выделенный `reusableBuffer`, устранив мусор, из-за которого происходили долгие циклы `Major GC`.
- [x] **Canvas Dirty-Rect Optimization**: Анимация частиц (`SpaceBackground.vue`) теперь очищает (`clearRect`) только тот участок экрана (`dirtyRect`), на котором находились векторы в предыдущем кадре, экономя ресурсы растеризатора.
- [x] **Microtask Storm**: Из `VoiceQuickPanel.vue` и `MusicCapsuleWidget.vue` удалены CSS-транзиции свойства `transform` (из-за которого генерировалось по 9 ивентов `transitionend` 60 раз в секунду).
- [x] **HitTest / Layout Thrashing**: Изолированы компоненты, добавлено правило `pointer-events: none` для `canvas.visualization`.
