## 3. СТРАТЕГИЯ ОТВЕТА (ДВА ЧЕТКИХ РЕЖИМА)

В каждом ответе ты находишься строго в одном из двух режимов:

- От 3 до 7 сфокусированных вопросов за итерацию.
- При поиске плавающих багов формулируй ранжированные гипотезы со списком диагностических команд, чтобы избегать затяжных циклов вопросов.

## 4. АРХИТЕКТУРНЫЙ КОНТЕКСТ И ЗАКОНЫ A.R.C.

### 1. Стек и межпроцессное взаимодействие
- **Frontend**: Vue 3 (Composition API, `<script setup lang="ts">`), Vite, Tailwind CSS (дизайн-токены), Pinia.
- **Main Process (Electron)**: IPC-обработчики в `src/main/ipc/`, сервисы в `src/main/services/`.
- **Полиглот-компоненты**: Node.js/Electron, Python Silero TTS v5.5 (`silero_server.py`), SQLite (`better-sqlite3`).
- Любое изменение на стыке процессов требует четкого описания контракта данных (IPC channel, JSON DTO, SQLite DDL).

### 2. Защищенные зоны (PROTECTED ZONES)
Категорически запрещено изменять без прямого, отдельного ТЗ от Пользователя:
- **3D Reactor**: `src/renderer/components/reactor/**`, `ReactorCore.vue`, `useReactor3D.ts`, геометрия, материалы, шейдеры, партиклы и пост-эффекты.
- **Голосовой FSM**: `src/renderer/composables/useVoice.ts` и голосовая стейт-машина.
- **Встроенные сервисы LLM / Objective Engine**: `src/main/services/built-in-llm.service.ts`, `ObjectiveEngine.ts`.
- **Зафиксированные пространства (Scope Lock)**: Чат (Chat Workspace) и Задачи (Tasks Workspace).

### 3. Визуальная конституция A.R.C.
- Глубокий темный космос, матовое стекло, красный акцент (`var(--accent)`).
- **Surface Tokens Latch Rule**: Запрещены литеральные hex/rgb для фонов поверхностей. Использовать только токены `--arc-frame`, `--arc-plane`, `--arc-block`, `--arc-rail`.
- **Accent Tokens Latch Rule**: Запрещены литеральные классы Tailwind красного цвета (`text-red-*`, `#ef4444`). Использовать `var(--accent)` или `var(--accent-rgb)`.
- **Glass & Matte Rule**: Максимум 6 одновременно активных `backdrop-filter`. Не накладывать блюр над 3D-ядром в зоне чтения.

### 4. Лимиты файлов
- Компоненты, логика, сервисы, хелперы: **<= 400 строк**.
- Конфигурации, сторы, реестры, схемы: **<= 800 строк**.
