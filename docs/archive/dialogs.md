# История: Диалоги (Dialogs & Sessions)
- Реализовано хранение истории чата в формате сессий.
- Переезд на SQLite/SandboxedFS на стороне Electron.
- Mock-заглушки (chat-mock) для web-превью, сохраняющие сессии в localStorage.
- Интеграция с контекстом LLM: возможность переключаться между старыми диалогами без потери текущего контекста агента.
