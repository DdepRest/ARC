# A.R.C. v1.0.0 — Памятка релиза (Personal Release Note)

Локальная памятка стабильного релиза **A.R.C. (Autonomous Reactor Core)** — автономного десктоп-ассистента для ежедневного личного использования.

---

### Суть системы
A.R.C. объединяет локальные LLM/API с операционной системой: исполнение инженерных сценариев, автоматизация терминала, управление файлами и голосовой диалог реального времени без задержек.

### Ключевые возможности Milestone v1.0.0:
- **Approval Flow & Безопасность**: Защитный слой подтверждения действий пользователя. Ни одна шелл-команда или деструктивная операция с файлами не выполняется без явного одобрения в UI.
- **Студийный синтез речи (Silero TTS v5.5)**: Локальный Python-бэкенд с нативной постобработкой звука (де-эссер, тоновый сдвиг, компрессор LUFS и реверберация).
- **Отказоустойчивое распознавание (STT)**: Архитектура «STT Never Dead» с мгновенным стартом Whisper Small int8 и подключением GigaAM CTC.
- **Dual-layer Content Security Policy**: Защита от инъекций на уровне сборки и рантайма.
- **Шифрование ключей через Windows DPAPI**: Аппаратная защита секретов провайдеров и безопасный AES-256 fallback.
- **7 специализированных пространств**: Команды, Аудио, Чат, Реактор, Инструменты, Цели и Настройки.

### Системные требования:
- **ОС**: Windows 10 / 11 (x64)
- **ОЗУ**: 8 ГБ (рекомендуется 16 ГБ)
- **Процессор**: 4+ ядра (поддержка AVX2)
- **Среда**: Node.js 20+, Python 3.10+ (для локального TTS)
