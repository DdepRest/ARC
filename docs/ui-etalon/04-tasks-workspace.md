# Эталон UI 04: Пространство задач (Tasks Workspace)

## 1. Смысловое назначение
Рабочее пространство планирования, декомпозиции и выполнения задач. Ориентировано на немедленное действие (Actionable-first) без визуального шума.

## 2. Архитектура и компоновка
- **Статус пространства**: Заблокировано от изменений структуры (Stage 4 & 5 Scope Lock).
- **Поверхность проекции**: `#0B0B0B` (непрозрачная, без размытия реактора).
- **Режимы представления**:
  - `List`: Иерархический список с чекбоксами, подзадачами и дедлайнами.
  - `Kanban`: Доска статусов (К выполнению, В процессе, Завершено).
  - `Matrix`: Матрица Эйзенхауэра (Срочно / Важно).
  - `FocusSprint`: Режим глубокой концентрации по технике Помодоро.

## 3. Визуальные стандарты
- **Карточки задач**: Фон `#0E0E0E`, окантовка `border-white/[0.07]`, скругление `rounded-[12px]`.
- **Приоритеты**: Цветовая индикация точками 2px (Критический, Высокий, Средний, Низкий).
- **Метаданные**: Время, теги и счетчики подзадач выполнены моноширинным шрифтом `text-[10px] font-mono text-[#7A7A7A]`.
