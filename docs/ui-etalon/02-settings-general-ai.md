# Эталон UI 02: Настройки — Общие и Интеллект (Settings: General & AI)

## 1. Смысловое назначение
Инженерная панель конфигурации базовых параметров ассистента и нейросетевых провайдеров. Открывается как голографическая проекция в центральной области над ядром реактора.

## 2. Геометрия проекции и оправа (v1.2.0-ui)
- **Габариты панели**: `min(88vw, 1240px) × min(74vh, 860px)`.
- **Адаптация (viewport <= 1366×768)**: `min(92vw, 1240px) × min(78vh, 860px)`.
- **Оправа**: Боковые поля 24px (16px в адаптиве), нижнее поле 20px (12px в адаптиве), заливка `#070707`.
- **Верхний блик оправы**: `1px rgba(255, 255, 255, 0.07)` только по верхнему краю.
- **Внешнее свечение**: `0 0 56px -12px rgba(var(--accent-rgb), 0.20)`.
- **Угловые засечки**: 4 уголка `8×8px`, толщина 1.5px, цвет `rgba(var(--accent-rgb), 0.85)`.
- **Поверхность контента**: Чистый непрозрачный `#0B0B0B`.

## 3. Навигационный рейл (Sidebar)
- **Ширина**: Фиксированная 232px.
- **Фон**: `#070707` (RGB: 7, 7, 7), визуально отделен от контента линией `border-r border-white/[0.06]`.
- **Поиск**: Поле ввода `bg-[#0E0E0E] border border-white/[0.07] rounded-[10px]`.
- **Элементы категорий**: Высота 34px, радиус 8px, текст `text-xs text-[#B4B4B4]`, активный элемент: `bg-white/[0.05] text-[#E8E8E8] font-medium` с левым акцентным маркером `2×14px bg-[rgb(var(--accent-rgb))]`.

## 4. Конструкция карточек настроек
- **Блок (SettingsBlock)**: Фон `#0E0E0E`, рамка `border border-white/[0.07]`, скругление `rounded-[14px]`.
- **Заголовок группы**: `arc-text-group-title text-[#E8E8E8]`.
- **Подзаголовок / подсказка**: `arc-text-hint text-[#909090]`.
- **Строка настройки (SettingsRow)**: Высота min 44px, разделитель `border-b border-white/[0.05]`.
- **Провайдеры (ProviderCard)**: Карточка провайдера `#0E0E0E` с тонким бейджем готовности и раскрывающейся консолью конфигурации без лишней вложенности.

- [x] Переключатели `ArcToggle` имеют плавную кинематику и тактильный отклик.
