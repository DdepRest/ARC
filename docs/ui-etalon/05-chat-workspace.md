# Эталон UI 05: Пространство диалога (Chat Workspace)

## 1. Смысловое назначение
Главное коммуникационное пространство текстового и мультимодального взаимодействия с ассистентом A.R.C.

## 2. Архитектура и компоновка
- **Статус пространства**: Заблокировано от изменений структуры (Stage 4 Scope Lock).
- **Поверхность проекции**: `#0B0B0B` (непрозрачная, без размытия реактора).
- **Область сообщений**:
  - Сообщения пользователя: Сдержанный темный фон `#141414` с мягким скруглением и тонким бордером `border-white/[0.08]`.
  - Ответы ассистента: Чистый матовый фон `#0E0E0E` с акцентным левым маркером и блоками подсветки синтаксиса кода.
  - Текст сообщений: Высококонтрастный `#E8E8E8` для отличной читаемости при длительной работе.

## 3. Зона ввода (ChatInputZone)
- **Форма**: Поле с мягким скруглением `rounded-2xl`, фон `#0E0E0E`, рамка `border-white/[0.08]`.
- **Фокус ввода**: Тонкое акцентное свечение `border-[rgba(var(--accent-rgb),0.5)]` без ослепляющих белых оверлеев.
- **Кнопки управления**: Интеграция микрофона, прикрепления файлов, выбора модели и отправки.

## 4. Контрольный чек-лист приёмки
- [x] Читаемость длинных ответов и блоков программного кода.
- [x] Отсутствие мерцания при стриминге ответов от LLM.
- [x] Скроллбар скрыт или выполнен в ультра-минималистичном виде без перекрытия текста.
