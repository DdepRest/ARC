# Эталон UI 01: Главный экран ядра (Core & 3D Reactor)

## 1. Смысловое назначение
Главный экран системы A.R.C. Является визуальным и смысловым ядром приложения: живой анимированный 3D-реактор (Three.js WebGL) в центре экрана на фоне глубокого нейтрально-чёрного космоса (`#000000`).

## 2. Колориметрия и оптическая плотность
- **Фон окружения**: Чистый `#000000` (RGB: 0, 0, 0).
- **Свечение реактора**: Реактор генерирует динамическое свечение по нормали в зависимости от состояния (`idle`, `listening`, `processing`, `speaking`).
- **Акцентная тема**: По умолчанию `CRITICAL_RED` (`--accent-rgb: 239, 68, 68`, `#EF4444`).
- **Вуаль реактора (Veil Ring)**: Ограничивает радиальное рассеивание света реактора, предотвращая засветку боковых доков и заголовка.
- **Вуаль над canvas**: Любой `backdrop-filter: blur(...)` строго запрещён для сохранения частоты 60 FPS.

## 3. Архитектура виджетов рабочего стола
- **Режим компоновки**: `dock` (боковые панели 340px) или `float` (свободное перемещение с сохранением координат).
- **Фон виджетов**: `#0B0B0B` (RGB: 11, 11, 11), непрозрачный.
- **Радиус скругления**: `rounded-[14px]` (14px).
- **Окантовка**: `1px solid rgba(255, 255, 255, 0.07)`.
- **Засечка в левом верхнем углу**: `w-3 h-[2px] bg-[rgb(var(--accent-rgb))]`.
- **Затемнение**: Управляется настройкой `widgetsDim` / `dimOpacity` (по умолчанию при наведении непрозрачность 100%, в покое 75-85%).

## 4. Контрольный чек-лист приёмки
- [x] Чернота космоса не искажена серыми или синими паразитными градиентами.
- [x] Отсутствуют backdrop-blur фильтры над холстом WebGL.
- [x] Реактор и кольца рендерятся без задержек и артефактов.
- [x] Текстовые метки телеметрии выполнены шрифтом `JetBrains Mono` (`font-mono text-[9px]`/`text-[10px] text-[#7A7A7A]`).
