# Эталон UI 03: Настройки — Голос и Система (Settings: Voice & System)

## 1. Смысловое назначение
Конфигурация аудио-тракта (STT Silero/Whisper/GigaAM, TTS Silero v5.5, VAD), системных параметров, безопасности, диагностики и управления локальным хранилищем данных `data/`.

## 2. Голосовой тракт (STT / TTS / Словари)
- **Конвейер распознавания**: Схема `SchemeView` на фоне `#0E0E0E` с точечными светодиодными индикаторами активности фаз конвейера.
- **Выбор диктора TTS**: Карточки дикторов `#0E0E0E` со скруглением `rounded-[12px]`, окантовкой `border-white/[0.07]`, активная карточка подсвечивается тонким акцентным бордюром `border-[rgba(var(--accent-rgb),0.5)]` без заливки ярким фоном.
- **Словарь исправлений**: Таблица и формы добавления замен выполнены в едином стиле инпутов `#0E0E0E` и кнопок `#141414`.

## 3. Системные разделы (Diagnostics, Performance, Storage, DangerZone)
- **Диагностика**: Инженерные метрики CPU, RAM, AudioContext, пинга провайдеров.
- **Хранилище**: Размер базы данных SQLite, журнала диалогов и кэшей с безопасной очисткой.
- **Опасная зона (DangerZone)**:
  - Фон: `#0E0E0E` с тонким предупреждающим бордером `border-rose-500/20`.
  - Кнопки сброса: `bg-rose-500/10 hover:bg-rose-500/20 text-rose-400 border border-rose-500/30`.
  - Модальное окно подтверждения: Двойное подтверждение действия для исключения случайного сброса.

## 4. Контрольный чек-лист приёмки
- [x] Отсутствуют яркие фоновые заливки статусов (используются семантические точки 1.5-2px).
- [x] Все служебные надписи соответствуют лестнице яркости (#E8E8E8, #B4B4B4, #909090, #7A7A7A).
- [x] Тест микрофона и синтеза речи работают без задержек.
