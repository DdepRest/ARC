# Эталон UI 06: Пространство памяти (Memory Workspace)

## 1. Смысловое назначение
Архивное долговременное хранилище фактов, пользовательских предпочтений, заметок и ассоциативных связей ассистента A.R.C.

## 2. Архитектура и компоновка
- **Поверхность проекции**: `#0B0B0B` (непрозрачная, без паразитных градиентов).
- **Структура**:
  - Верхняя панель: Поиск по семантическому индексу, фильтры по категориям и дате.
  - Сетка карточек памяти: Адаптивная сетка 2-3 колонки.
- **Карточки памяти**:
  - Фон: `#0E0E0E`, рамка `border-white/[0.07]`, скругление `rounded-[14px]`.
  - Заголовок и категория: `text-xs text-[#E8E8E8]` с моноширинным бейджем категории `text-[9px] font-mono text-[#7A7A7A]`.
  - Текст факта: `text-xs text-[#B4B4B4]` с комфортным межстрочным интервалом.
  - Действия: Редактирование, закрепление, удаление с подтверждением.

## 3. Контрольный чек-лист приёмки
- [x] Карточки не сливаются с фоном благодаря контрасту `#0E0E0E` vs `#0B0B0B`.
- [x] Отсутствуют яркие фоновые бейджи (используются контурные чипы `border-white/[0.08]`).
- [x] Плавный скролл при большом объеме записей в памяти.
