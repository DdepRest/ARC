# Эталон UI 08: Виджеты ядра и телеметрии (Core Widgets & Technical HUD)

## 1. Смысловое назначение
Информационные HUD-виджеты рабочего стола, отображающие оперативную телеметрию (FPS, таймлайн, медиа, роутер, состояние 3D-реактора) непосредственно над рабочим экраном ядра.

## 2. Архитектура и компоновка (v1.2.0-ui)
- **Базовый шелл (`HudWidgetShell.vue`)**:
  - Поверхность: `#0B0B0B` (RGB: 11, 11, 11), чистая матовая заливка.
  - Размытие: `backdrop-filter` полностью удалён (запрещён над Three.js canvas).
  - Радиус скругления: `rounded-[14px]` (14px).
  - Рамка: `border border-white/[0.07]`.
  - Угловая засечка: `w-3 h-[2px] bg-[rgb(var(--accent-rgb))]` в левом верхнем углу (фирменный маркер A.R.C.).
  - Тень: `0 4px 20px rgba(0, 0, 0, 0.6)`.
- **Заголовок виджета**:
  - Высота хедера: `padding: 9px var(--widget-padding)`.
  - Типографика названия: `text-xs font-mono font-medium text-[#E8E8E8]`, нормальный регистр (без кричащего CAPS).
  - Иконки управления: Сворачивание, скрытие, drag-зона с иконкой `GripVertical`.

## 3. Каталог виджетов
1. **ReactorTechnicalHUD**: Состояние реактора, пинг, микрофон, активная нейросеть.
2. **AssistantActionTimeline**: Пошаговый пайплайн обработки голосовой/текстовой реплики.
3. **SmartRouterDiagram**: Маршрутизация запросов (локальный инференс vs облачные API).
4. **MusicCapsuleWidget**: Интеграция с медиаплеером (VK Music), управление треками.
5. **PerformanceProfiler**: Мониторинг FPS, времени кадра, использования WebGL и памяти.
