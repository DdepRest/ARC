# Эталон UI 07: Пространство команд и макросов (Commands Workspace)

## 1. Смысловое назначение
Инженерный каталог системных действий, скриптов автоматизации, макросов и шорткатов. Позволяет связывать голосовые команды с исполняемыми сценариями.

## 2. Архитектура и компоновка
- **Поверхность проекции**: `#0B0B0B` (непрозрачная).
- **Структура**:
  - Каталог команд: Список зарегистрированных команд с фильтрацией по категориям (Система, Медиа, Продуктивность, Сеть).
  - Редактор макросов: Визуальная палитра действий, цепочки вызовов и параметры аргументов.
- **Элементы управления**:
  - Карточки действий: Фон `#0E0E0E`, рамка `border-white/[0.07]`, скругление `rounded-[12px]`.
  - Моноширинные шорткаты: `kbd` кейкапы `bg-white/[0.05] border border-white/[0.12] rounded-[6px] text-[10px] font-mono text-[#E8E8E8]`.
  - Статусы выполнения: Точечные индикаторы `bg-emerald-400` / `bg-rose-400` (диаметр 2px).

## 3. Контрольный чек-лист приёмки
- [x] Строгая инженерная плотность без пустых отступов и лишней декорации.
- [x] Понятная визуализация цепочек макросов.
- [x] Тестирование исполнения команды с мгновенным выводом лога выполнения.
